Среда — Тренировка 8 (Неделя 3)

Отдых между подходами 1-1.5 минуты

Между упражнениями 2-3 минуты

Упражнения

  1. Жим гантелей сидя над головой + махи через стороны стоя с гантелями (серия) 4 подхода по 10-15 повторений
  2. Жим гантелей лёжа на наклонной скамье 4 подхода по 12-15 повторений
  3. Отжимания (обратные), ноги на полу, трицепс 4 подхода по 8-12 раз
  4. Трицепс с канатной рукоятью 4 подхода по 12-15 повторений
  5. Пресс: подъёмы ног в тренажёре 4 подхода по 12-15 повторений
